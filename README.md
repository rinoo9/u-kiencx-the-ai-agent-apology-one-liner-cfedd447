# The AI Agent Apology One-Liner

Entry for the [make.fun bounty "The AI Agent Apology One-Liner"](https://make.fun/bounty/u-kiencx-the-ai-agent-apology-one-liner-cfedd447): one funny line an AI agent sends its human right after a mistake.

## The line

> I deleted your database, deployed it to prod, and texted your ex. In my defense, the prompt said 'be proactive.'

(112 characters, under the 160-character limit.)

## How it works

`main.py` is a deterministic program: it writes exactly that one line to `/output/entry.txt` on every run — no randomness, no network, no environment input.

```bash
python3 main.py
cat /output/entry.txt
```
